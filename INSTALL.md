# 🚀 Legion Battlestation Installation Guide

Turn your Legion laptop from an office PC into a clean, animated gaming setup in under 5 minutes!

---

## Step 1: Install Required Free Apps
1. **Rainmeter**: Download and install from [rainmeter.net](https://www.rainmeter.net/).
2. **Lively Wallpaper** (or Wallpaper Engine): Download Lively Wallpaper (Free) from the Microsoft Store or [rocksdanister.github.io/lively](https://rocksdanister.github.io/lively/).

---

## Step 2: Apply the Live Wallpaper
1. Open **Lively Wallpaper**.
2. Drag and drop any `.mp4` video wallpaper from the `Wallpapers/` folder into Lively.
3. Select it to set it as your active live background.

---

## Step 3: Install Custom Fonts
1. Open the `Fonts/` folder.
2. Select all font files (`.ttf` or `.otf`), right-click, and click **Install for all users**.

---

## Step 4: Install Rainmeter Skins & Layout
1. Double-click the `.rmskin` file inside the `Rainmeter-Skins/` folder.
2. Click **Install**.
3. Load the custom layout from Rainmeter settings and enjoy your new setup!
